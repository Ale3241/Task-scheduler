# Task Scheduler

## Descripción

Aplicación web desarrollada con HTML, CSS y JavaScript para organizar y administrar tareas desde una interfaz gráfica.

El proyecto permite practicar la manipulación del DOM, el manejo de eventos y la implementación de funcionalidades interactivas con JavaScript.

## Funcionalidades

- Crear tareas.
- Consultar y administrar las tareas registradas.
- Buscar tareas.
- Filtrar tareas según las opciones disponibles.
- Actualizar el estado de las tareas.
- Interactuar con una interfaz web dinámica.

## Tecnologías utilizadas

- **HTML5:** estructura de la aplicación.
- **CSS3:** estilos y presentación visual.
- **JavaScript:** lógica e interactividad.

## Instalación y ejecución

Clona el repositorio:

```bash
git clone https://github.com/Ale3241/Task-scheduler.git
cd Task-scheduler
```

Abre el archivo `index.html` en tu navegador.

También puedes utilizar la extensión Live Server de Visual Studio Code, si está instalada, para ejecutar el proyecto durante el desarrollo.
